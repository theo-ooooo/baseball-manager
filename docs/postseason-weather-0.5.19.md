# 0.5.19 포스트시즌 일정과 경기 날씨

## 경기 진행

- 현재 게임의 포스트시즌은 정규시즌 상위 4팀, 준결승 3전 2선승, 챔피언십 5전 3선승이다. 실제 KBO 5팀 포스트시즌이나 각국의 모든 리그 규칙을 그대로 재현하는 변경은 아니다.
- 진출 확정 시 서버가 날짜와 고유 ID가 있는 차전별 일정을 만든다. 승부가 결정되지 않았을 때만 필요한 경기는 `conditional`, 조기 종료 후 남은 경기는 `cancelled`로 표시한다.
- 양쪽 준결승이 모두 끝난 다음 날부터 결승을 편성한다. 완료 경기의 ID·점수와 시리즈 승수를 함께 저장하며 정규시즌 순위에 포스트시즌 승패를 더하지 않는다.
- 이전 저장에서 이미 포스트시즌을 진행 중이면 기존 시리즈 승수와 경기 기록을 보존하고 남은 차전의 날짜를 보완한다. 기록하지 않았던 과거 대진이나 이미 끝난 시즌의 일정을 추정해 만들지는 않는다.

## 날씨와 취소

- 실제 기상 예보가 아닌 게임 생성 날씨다. 시즌 고정 시드·홈 구단·날짜로 날씨를 결정하므로 새로고침과 미리보기가 경기 결과 난수를 소비하지 않는다.
- 홈, 경기 전 브리핑, 프리뷰, 경기 일정에서 날씨를 공용 표시한다. 새로 치른 경기의 결과에는 당시 날씨를 보존한다. 날씨 정보가 없던 과거 결과에 새 날씨를 소급 표시하지 않는다.
- 정규시즌·포스트시즌의 강한 비와 그라운드 정비 사정은 경기 취소 및 재편성에 영향을 준다. 취소 자체로 승패·출전·선발 등판을 기록하지 않는다. 취소일에는 기존 휴식·훈련·구단 업무가 진행된다.
- 정규시즌은 두 구단 모두 비어 있는 가장 이른 다음 날짜에 같은 홈 대진을 편성한다. 마지막 경기가 밀리면 정규시즌 종료도 연기한다. 포스트시즌은 같은 시리즈의 남은 차전을 함께 하루 밀고 다른 시리즈의 편성은 유지한다. 다시 기상 취소되면 재편성할 수 있다.
- 이미 시작한 경기는 취소하지 않고 시작 당시 날씨를 유지한다. 연습경기는 날씨만 표시하며 기존 일정대로 진행한다. 온도·바람으로 타구 물리나 타격 확률을 바꾸거나 경기 도중 강우 콜드를 판정하는 기능은 이번 범위에 포함하지 않는다.
- KBO·NPB·MLB의 지붕 있는 주 구장 15곳은 비를 피해서 진행하는 게임 모델이다. 개폐식 지붕은 닫을 수 있다고 취급하며 실제 당일 개폐 상태, 임시·지방 구장, 전 세계 모든 구장의 시설 차이를 재현하지 않는다. 메타데이터와 공식 자료 링크는 `apps/api/seed/ballparks-2026.json` 및 D1 이관 `0024_covered_ballparks.sql`에 있다.
