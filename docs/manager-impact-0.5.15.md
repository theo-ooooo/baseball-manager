# 감독 능력과 경력 — 0.5.15

내 감독의 표시 전용 능력을 실제 경기와 구단 운영에 연결하고 감독 상세 페이지를 개편했다.

| 능력 | 적용 위치 |
| --- | --- |
| 작전·경기 운영 | 타석의 컨택 판정, 수비 조직력, 지시한 번트·도루 수행 |
| 투수 교체·불펜 운용 | 투구 전력·제구 보조, 자동 투수 교체의 피로 기준 |
| 선수 육성 | 내 선수의 훈련 성장과 노장 하락 속도. 기존 AI 구단 성장 배율과 같은 산식 사용 |
| 선수단 장악 | 경기 집중력과 직접 진행한 경기 전·후 대화의 사기 반응 |
| 선수 보는 눈 | 완료된 스카우트 보고 신뢰도와 관찰 범위 |

실제 타석 시뮬레이션은 양 팀 감독에게 같은 보정을 적용한다. 코치에게 경기 지휘를 맡겨도 경기 시작 때 고정한 감독 능력이 유지된다. 인터뷰 위임은 담당 코치 지도력을 사용하고 자동 언론 응대는 기존처럼 사기를 변경하지 않는다. AI끼리의 간략 경기 계산은 기존 제한된 전력 보너스를 유지한다.

경기 보정은 능력 55를 기준으로 차이를 -35~40에 제한한다. 컨택은 작전·동기 합계 최대 +0.010, 투구 전력 최대 +2.0, 제구 최대 +2.4다. 성장 배율은 육성 20~95에서 0.82~1.27이고 잠재력 상한을 유지한다. 대화는 직접 ±2, 위임 ±1 상한을 지킨다. 실제 야구 또는 FM의 내부 수식이라고 주장하지 않는 게임 밸런스다.

FM의 [공식 감독 설정 안내](https://www.footballmanager.com/the-dugout/perfecting-your-manager-fm26)는 배경·지도 스타일·성향이 감독 능력과 게임 내 역할에 영향을 준다고 설명한다. 이 변경은 그 방향을 참고했으며 FM의 비공개 경기 공식을 재현한 것이 아니다.

## 저장과 비용

- 새 `liveMatch.managers`에 홈·원정 능력과 버전 1을 고정한다. 타임라인 재생성은 이 값만 읽으므로 D1의 경량 경기 명령 경로에 전체 감독 명단 조회를 추가하지 않는다.
- 이 필드가 없는 진행 중 경기는 종전 보정을 유지한다. 새 난수 호출은 없으며 이미 소비한 플레이는 변경하지 않는다.
- 사용자·가상 감독의 배경은 서버에서 한 번 생성한다. 게임 난수를 소비하지 않고 저장·평판 변화·이직 후에도 유지한다. 기존 저장의 배경이 없으면 첫 재임 기록을 기준으로 보완한다.
- 실명 이력은 D1 카탈로그에서 읽는다. `0022_manager_backgrounds.sql`은 메타데이터와 카탈로그 버전만 갱신하며 기존 저장·계약·경기 기록을 직접 변경하지 않는다.

## 상세 페이지와 경력 범위

상단에 이름·소속·지도 스타일·취임 후 시즌 성적·평판을 보여준다. 프로필에는 다섯 능력의 적용 설명, 이사회 평가와 계약 요약을 배치하고 경력과 계약을 별도 탭에서도 볼 수 있게 했다. 상태는 `useManagerPersonProfile`에 두며 화면 컴포넌트가 게임 상태를 변경하지 않는다.

경력 탭은 게임에서 쌓은 취임·퇴임·코치 전향 기록과 부임 전 배경을 구분한다. 가상 배경 성적을 실제 플레이 성적에 합산하지 않는다. 실명 이력은 KBO 10개 구단의 카탈로그 감독에 대해 확인한 주요 경력을 우선 제공하며 각 항목에 출처를 붙였다. 모든 국가 감독의 전체 이력을 수록한 것은 아니다. 원본은 `apps/api/seed/manager-backgrounds-2026-09-14.json`이며 런타임에서는 이 파일을 읽지 않는다.

## 검증

- 최종 프로덕션 빌드, 343개 테스트, 타입·린트·포맷 검사 통과.
- 동일 선수·난수에서 공격 감독의 작전 능력과 수비 감독의 불펜 능력을 각각 바꾸면 실제 안타·아웃 판정이 변한다.
- 저장 복원·경량 시뮬레이터·기존 경기 호환·코치 위임의 진행 기록 보존, 28일 성장/하락·대화·스카우트 보고·배경 유지 검증.
- 실제 로컬 Worker/D1에서 10명 카탈로그 이력을 확인하고, 새 사용자 프로필과 김태형 프로필의 경력·출처, 계약 탭·홈 이동을 브라우저로 확인했다. PC 1280px, 모바일 390px에서 가로 넘침과 브라우저 오류 없음.
- 긴 시즌 다수 표본의 승률 균형 검증은 이번 확인에 포함하지 않았다. 이전 Claude 검토의 네 결함은 이 변경과 별개로 남아 있다.
