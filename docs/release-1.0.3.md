# DUGOUT 1.0.3 — 재계약 기간 보장

시즌 말에 1년 재계약한 선수가 다음 시즌 시작과 동시에 FA로 풀리는 문제를 수정했다. 재계약 기간을 체결한 시즌에 바로 차감하던 계산이 원인이었다.

- 2026년에 1년 재계약하면 **2027시즌까지**, 3년 재계약하면 **2029시즌까지** 보장한다. 현재 시즌에도 소속을 유지하므로 서명 직후 잔여 기간에는 현재 시즌을 포함한 2시즌/4시즌이 표시된다.
- 제안·합의·서명 화면과 완료 보고에서 계약이 적용되는 시즌을 확인할 수 있다. 일괄 재계약에도 동일하게 적용한다.
- 연봉은 기존대로 서명 즉시 적용한다. 서명 비용·수수료와 FA 신규 영입의 체결 시즌 기준 기간 계산은 유지한다.

새로 최종 서명하는 재계약부터 적용한다. 기존 계약 기간을 일괄 늘리거나 이미 FA가 된 선수를 자동 복원하지 않는다. 저장 초기화나 D1 스키마 변경은 필요하지 않다.

프로덕션 빌드, 전체 448개 테스트, 타입·린트·포맷 검사를 통과했다. 양현종의 1년 재계약 서명→다음 시즌 진입을 실제 로컬 Worker/D1 브라우저에서 확인했다. 계약 기간 계산은 1년/3년 재계약의 여러 시즌 유지·만료와 FA 신규 영입의 기존 기준을 함께 회귀 검증했다. 상세 플레이 기록은 [두 시즌 실사용 기록](playthrough-2026-09-16.md), 최종 배포 식별자는 `WORKLOG.md`에서 확인할 수 있다.
