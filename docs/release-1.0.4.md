# DUGOUT 1.0.4 — 감독의 다음 직장과 경기 기록

무직에서 지원·면접·취임하고, 계약 만료 후 다시 구직하는 실제 플레이에서 발견한 오류를 수정했다.

- 계약 만료·재계약 불발을 자진 사퇴와 구분하고, 마지막 시즌의 퇴임 순위를 보존한다.
- 무직의 새 시즌 안내를 채용 센터로 연결한다.
- 채용 협상의 최신 메일만 ‘처리 필요’로 표시하고, 이사회 답변 대기 중 불필요한 중단을 줄인다.
- 이적 후 홈·일정·브리핑·경기 전 인터뷰가 현재 구단의 경기 기록을 사용한다. 취임 전 점수 기록을 포함하며 이전 아카이브는 보존한다.
- 점수만 보관한 경기는 리플레이 대신 ‘점수 기록’으로 표시한다.

저장 초기화나 D1 스키마 변경은 필요하지 않다. 이미 잘못 저장된 과거 퇴임 순위를 추정해 고치지는 않는다. [플레이 경로와 재미 평가](playthrough-career-2026-09-16.md), 검사·배포 결과는 `WORKLOG.md`에서 확인할 수 있다.

프로덕션 빌드, 전체 453개 테스트, 타입·린트·포맷 검사를 통과했다. 실제 로컬 Worker/D1에서 변경된 고용 상태 전환, 수신함 집계, 구단 경기 기록과 모바일 표시를 확인했다.
