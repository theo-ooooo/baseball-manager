# DUGOUT 1.0.6 — 경기 전에 수신함 확인

안 읽은 일반 메일이 남아 있어도 경기로 넘어가던 문제를 수정했다.

- 경기 시작, 코치 경기 위임, 새 연전 위임 전에 **수신함 확인 · 남은 건수**를 표시하고 먼저 온 메일로 안내한다.
- 마지막 메일을 읽으면 바로 경기 준비로 넘어간다. 경기 시작과 함께 읽음 기록을 저장하므로 다시 읽거나 별도로 저장할 필요가 없다.
- 서버에서도 안 읽은 메일을 건너뛰는 경기 시작 요청을 차단한다. 이미 진행 중인 경기와 승인한 휴가·진행 중인 연전 위임은 이어진다.

전체 462개 테스트, 타입·린트·포맷과 프로덕션 빌드를 통과했다. 실제 로컬 Worker/D1에서 메일 읽기 → 경기 준비 → 프리뷰와 모바일 안내를 확인했다. 기존 저장을 그대로 이어 쓸 수 있으며 D1 스키마 변경은 없다. 공개 게시 결과는 WORKLOG.md에 기록한다.

공개 배포 완료: **1.0.6 · 빌드 9c49310**. 기존 1.0.5 테스트 저장에서 수신함 우선 안내와 실제 서버의 경기 시작 차단을 확인했다.
