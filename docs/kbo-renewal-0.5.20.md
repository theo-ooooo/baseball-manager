# 0.5.20 KBO 순위별 포스트시즌과 감독 재계약 진행

## 대진·일정

KBO는 단축 모드에서도 상위 5팀이 진출한다. 1위는 한국시리즈, 2위는 플레이오프, 3위는 준플레이오프에 직행하며 4·5위부터 와일드카드전을 치른다. 직행 구단은 해당 라운드까지 경기를 치르지 않으며 탈락·시즌 종료로 판정하지 않는다.

- 와일드카드: 최대 2경기, 모두 4위 홈. 4위는 1승 또는 1무, 5위는 2승이 필요하다. 진출 어드밴티지를 실제 승수와 별도로 보관하므로 치르지 않은 승리를 기록하지 않는다.
- 준플레이오프·플레이오프: 5전 3선승, 상위 순위 홈을 A로 보아 A-A-B-B-A 순서다.
- 한국시리즈: 7전 4선승, A-A-B-B-B-A-A 순서다.
- 홈 구장이 바뀔 때 이동일 하루를 두고, 다음 라운드는 이전 라운드 종료 후 하루를 쉬고 시작한다. 정규시즌과 와일드카드 사이에도 하루를 쉰다. 비·그라운드 취소는 기존 재편성 기능을 사용한다.
- 다른 리그는 기존 상위 4팀·준결승 3전 2선승·결승 5전 3선승을 유지한다.

공식 근거: [KBO 경기 운영 체제](https://m.koreabaseball.com/About/GameManage.aspx), 라운드 사이 이동일 참고 [KBO 2025 포스트시즌 일정 발표](https://www.koreabaseball.com/MediaNews/Notice/View.aspx?bdSe=11694). 실제 2026 포스트시즌의 확정 날짜를 가져온 것이 아니라 게임 시즌 결과에 따라 일정을 생성한다.

기존 저장은 **아직 어느 팀도 경기를 치르지 않았고 실시간 경기도 없는** 구형 KBO 준결승만 5팀 대진으로 전환한다. 이미 완료하거나 진행 중인 경기·승수는 보존하며 그 시즌의 구형 대진을 끝까지 유지한다. API 조회는 응답을 보완할 뿐 D1 상태/revision을 쓰지 않고 다음 변경 요청에 저장한다. 이전 시즌 기록은 재작성하지 않는다. 0.5.19 문서의 KBO 상위 4팀 설명은 이 버전부터 위 조건으로 대체된다.

현재 시뮬레이터의 포스트시즌 연장전은 기존의 승패 결정 방식을 유지한다. 결과 기록기는 와일드카드 무승부 진출을 처리하지만 실제 KBO의 15회 무승부·추가 경기 개최장 전체 규정, 정규시즌 동률 결정전까지 구현한 것은 아니다. 동률 순위는 기존 승률·승수·득실차·구단 ID 순서로 결정한다.

## 화면과 재사용

리그 순위표는 정규시즌 중 ‘현재 PS 진출권’과 5위 경계선을 표시한다. 정규시즌 종료 후에는 확정된 시드로 한국시리즈·플레이오프·준플레이오프 직행 또는 와일드카드 진출을 표시한다. 다른 리그를 열었을 때 내 구단 포스트시즌 확정 표시를 섞지 않는다. 대진판은 상위 순위 팀이 어느 라운드에서 기다리는지 구단명과 함께 보여 준다.

- 공통 규칙·판정: `packages/shared/src/postseason.ts`, `season-status.ts`
- 서버 편성·진출·이전 저장 보완: `apps/api/src/domain/postseason-calendar.ts`
- 대진판 상태 계산: `use-postseason.ts`
- 순위표 계산: `use-standings-table.ts`
- 공통 표시: `PostseasonPanel`, `PostseasonSeriesCard`, `PostseasonWaitingCard`, `PostseasonQualificationBadge`

## 재계약 답변 대기 막힘

시즌 종료 후 감독이 재계약 조건을 수정해 보내면 이사회 답변은 다음 날짜에 도착한다. 기존 상단 버튼은 무조건 ‘다음 시즌’을 실행하여, 답변 날짜를 진행하지 못한 채 ‘재계약 후 진행’ 오류가 반복됐다.

수정 후 상단은 ‘재계약 답변까지 진행’ → ‘재계약 조건 확인/서명’ → ‘다음 시즌’ 순서로 연결한다. 협상 화면에도 ‘하루 진행 · 이사회 답변 받기’를 제공하고, 계약 관리 화면의 다음 시즌 버튼도 진행 중인 재계약으로 연결한다. 날짜 진행·서명은 기존 서버 명령을 사용한다. 차기 시즌 개막 경계 날짜에서도 대기 중인 재계약 답변을 먼저 처리하며 서명 전 자동 시즌 전환을 하지 않는다.

진행 판단은 `manager-flow.ts`의 순수 함수, 입력/비동기는 `use-manager-contract-negotiation.ts`, 날짜·계약 변경은 서버에 둔다. 공개 버전은 0.5.20, 기존 D1 카탈로그 `world-2026-09-14-v17`과 호스팅 식별자를 유지한다. 추가 테이블·외부 요청은 없다.
