# 공개 서비스 두 시즌 플레이 점검 — 2026-09-16

공개 1.0.1에서 새 브라우저 세션과 새 KIA 단축 커리어를 만들어 실제 화면으로 진행했다. 시작 당시 기존 저장이 없는 것을 확인했다. 공개 API로 경기를 건너뛰거나 결과를 주입하지 않았으며, 화면 조작과 읽기 전용 저장 조회로 검증했다. 수정본 1.0.2는 별도 로컬 Worker/D1에서 확인했다.

## 진행 결과

| 시즌 | 정규시즌 | 포스트시즌 | 실제 진행 경기 |
| --- | --- | --- | --- |
| 2026 | 12승 6패, 1위 | 한국시리즈 직행 → 삼성에 4승 무패 우승 | 22경기 |
| 2027 | 16승 2패, 1위 | 한국시리즈 직행 → 한화에 4승 3패 우승 | 25경기 |

단축 모드의 KBO 정규시즌은 이번 커리어에서 팀당 18경기였다. 2시즌 정규 36경기와 한국시리즈 11경기, 총 47경기를 마쳤다. 첫 경기 초반은 직접 지휘하고 나머지는 코치 경기/연전 위임을 주로 사용했다. 이 한 커리어의 높은 승률만으로 전체 밸런스가 적절하다고 판단하지 않는다.

## 실제 화면에서 확인한 흐름

- 경기 전 카드 5장 중 3장 선택, 증강 확인, 기회 상황의 추천 카드 사용과 보유 수 감소. 사인 성공 삼진 표시 뒤 경기가 계속 진행됐다. 첫 경기 보고에는 우리와 상대 모두 카드 3/3 사용, 증강 사용 또는 무효화가 기록됐다.
- 경기 후 코치 인터뷰에서 선수 11명의 사기가 각각 1 올랐다. 모든 위임이 무조건 차분한 선택으로 끝나는 문제는 이번 경우 재현되지 않았다.
- 트레이드 추천에서 삼성 장우진을 받고 성영탁을 내주는 안을 선택했다. 현금 조건을 수정해 역제안을 받은 뒤 같은 협상에서 3차 제안과 최종 교환까지 완료했다. 최종 선수단 변경과 현금 18.9억 수입을 저장 데이터로 확인했다.
- 일괄 재계약 문서로 18명에게 제안했다. 합의와 역제안이 나뉘어 도착했고 모두 최종 서명했다. 양현종은 1년, 나머지는 3년을 제시했으며, 체결 후 모달이 닫혔다. 다음 시즌 네일·서주원 등의 잔여 계약은 3년에서 2년으로 줄었다.
- 감독 재계약 연봉을 구단 제안보다 5% 높여 보낸 뒤 `하루 진행 · 이사회 답변 받기` → 합의 → 최종 서명 → 다음 시즌 진입을 확인했다. 이전 시즌 12승 6패·1위·우승 기록이 남았다.
- 1위는 와일드카드·준플레이오프·플레이오프에 참가하지 않고 기다렸다. 일정 화면에서 앞선 라운드의 차전·결과·예정일을 확인했다. 2027 한국시리즈는 7차전까지 진행됐다.
- 육성 선수 박승현은 한국시리즈 실제 7경기 선발, 4안타를 기록했고 3번째 선발 경기에서 목표 달성 표시가 생겼다. 동명이인 장민준은 서로 다른 나이·포지션·ID였으며, 출전하지 않은 20세 DH의 육성 진행도는 0으로 유지됐다.
- 부상 보고·선수 면담·감독 제안에서 위임이 멈추고, 답변한 뒤 다시 이어졌다. 공개 화면에서 JS 예외는 수집되지 않았다. 아래 정상 거절의 저장 경고 오표시는 별도로 재현했다.

## 발견 후 1.0.2에서 수정한 사항

1. **정상 거절을 저장 실패로 표시:** 중요한 보고나 계약 답변이 남은 상태에서 연전 위임을 누르면 서버의 400 응답이 빨간 저장 실패 안내로 나왔다. 정상적인 규칙 거절은 이유만 알리고, 네트워크 실패·손상 응답 등 저장 여부가 불확실할 때만 복구 경고를 유지한다. 성공적인 저장 재조회와 리비전 충돌 복구는 경고를 해제한다.
2. **위임이 막힌 이유와 처리 화면 연결:** 서버와 화면이 동일한 제한 판단을 쓴다. 필수 면담은 정확한 보고, 감독 제안은 해당 면접·계약, 선수/코치 계약과 트레이드·드래프트는 각 처리 화면으로 연결한다. 이미 읽은 미결 계약도 무시하지 않는다.
3. **지난 날짜 안내와 잘못된 휴식 표시:** 연전 위임 후 날짜가 바뀌어도 이전 날짜 도착 안내가 남았다. 완료된 안내는 현재 날짜·라운드·시즌·구단과 맞을 때만 표시하며, 진행 달력의 지난 경기는 상대와 실제 스코어를 표시한다. 진행 상태와 비동기 흐름을 커스텀 훅으로 분리했다.
4. **작년 연전 결과의 새 시즌 잔류:** 시즌 전환 시 이전 연전 상태를 정리하고, 이미 저장된 이전 시즌/다른 구단 상태도 화면에 표시하지 않는다.
5. **코치 설명 정리:** 상황에 따라 선택하는 인터뷰를 항상 “차분한 메시지”라고 안내하던 문구를 고쳤다. 새 선발 추천 보고에서 사기가 `46.399999999999984`처럼 나오던 표시를 반올림했다. 이미 저장된 과거 보고서 본문은 소급 변경하지 않는다.

## 검증과 남은 개선점

프로덕션 빌드, 전체 446개 테스트, 타입·린트·포맷 검사를 통과했다. 날짜/시즌 안내와 요청 실패·재시도·리비전 복구에 새 회귀 테스트 6개를 추가하고, 기존 연전 차단 및 시즌 전환 테스트를 보강했다.

수정본의 실제 로컬 Worker/D1에서 경기 진행 후 달력 스코어와 안내 제거를 확인했다. 390px 화면에서 보고/감독 제안 버튼이 정확한 화면으로 이동하며 게임 변경 요청을 보내지 않는 것을 확인했다. 로컬 프록시에서 400 응답을 주입해 오류 이유만 표시되고 저장 실패 경고가 생기지 않는 것도 확인했다. 테스트 세이브와 화면 자료는 Git에 넣지 않는다.

아직 **일괄 제안 뒤 최종 서명은 선수별로 반복**해야 한다. 코치 위임 중에도 출전 불만 면담과 계약 보고가 자주 멈춤을 만들어 긴 흐름이 끊기는 느낌이 있다. 두 기능의 처리 빈도·묶음 처리는 다음 UX 개선 대상이다. 이번 수정에서 필수 결정을 자동으로 수락하거나 생략하지는 않는다. 이번 확인 범위는 KIA 단축 2시즌이며 다른 국가 리그, 장기 커리어, 모든 협상 거절 경우와 전체 화면의 접근성을 검증한 것은 아니다.
