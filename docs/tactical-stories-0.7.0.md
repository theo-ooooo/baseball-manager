# 0.7.0 — 상대의 전술 대응과 주전 경쟁

## 벤치 수싸움

경기 준비 화면에서 우리 팀과 상대의 대응 및 판단 근거를 확인한다. `수비 대응 선택` 모달에서 직접 지시할 수 있고, 선택하지 않으면 코치가 판단한다. 경기장 프리뷰에서는 확정한 대응을 보여 준다. 대응은 매 경기 새로 정하며 사인·일회용 카드·증강과 함께 경기 계산에 반영한다. 코치 위임에서도 동일한 양쪽 수비 효과를 사용한다.

판단에는 이 커리어에서 실제로 관측한 팀별 최근 4경기의 타석, 강공·볼 고르기, 도루 시도, 홈런, 볼넷을 사용한다. 연습경기는 제외하며 최소 2경기·45타석이 모이기 전에는 균형 수비를 유지한다. 도루 3회 이상은 주자 견제, 강공 비중 45% 이상 또는 홈런 3개 이상·타석당 4% 이상은 장타 경계, 볼 고르기 비중 45% 이상 또는 볼넷 비율 12% 이상은 스트라이크 선점으로 대응한다. 여러 조건이 겹치면 이 순서를 적용한다.

| 대응 | 경기 계산에 더하는 값 | 대가 |
| --- | --- | --- |
| 균형 수비 | 추가 보정 없음 | 특정 패턴에 추가 대응 없음 |
| 주자 견제 | 도루 성공 확률 −0.06 | 주자가 있으면 볼넷 문턱 +0.006, 컨택 보정 +0.008 |
| 장타 경계 | 안타 발생 후 홈런 판정값 −0.025 | 볼넷 문턱 +0.01 |
| 스트라이크 선점 | 볼넷 문턱 −0.016 | 컨택 보정 +0.01, 안타 발생 후 홈런 판정값 +0.015 |

이는 기존 확률 계산에 더하는 값이며 실제 홈런율·승률의 퍼센트 변화와 같지 않다. 기존 확률 상·하한을 유지한다. 양쪽 수비에 같은 계산식을 사용하고 추가 난수 추첨은 하지 않는다. 현재 경기의 미래 로그나 아직 실행하지 않은 지시를 분석 자료로 사용하지 않는다. 코치의 수비 대응은 관측된 기록을 기준으로 자동 선택하며, 모든 상대 감독이 독립적으로 학습하는 모델은 아니다. 상대의 공격 성향은 실제 도루·홈런·볼넷 관측으로 판단한다.

시작 시 `liveMatch.duel`에 양쪽의 선택·근거를 고정한다. 선수 교체·카드·사인·재접속으로 수비 대응을 재추첨하지 않는다. 이전 버전에서 시작해 이 필드가 없는 경기는 추가 보정 없이 이어간다. 최종 경기 결과에도 대응을 저장하고 수신함 경기 보고에 남긴다. 관측은 구단별 4건, 전체 48건까지 보관하며 전 세계 경기 아카이브를 추가 조회하지 않는다.

## 선발 기회로 이어지는 주전 경쟁

감독이 육성 지명한 23세 이하 타자가 선발 2경기 이상을 기록하고 다시 선발로 나섰을 때, 같은 포지션의 28세 이상 기존 주전이 최근 팀 3경기에 출전하지 못했다면 방침을 묻는다. 베테랑은 1군·핵심/주전 역할·컨디션 65 이상이어야 하며 부상·대표팀 차출·기존 출전 약속·미처리 면담이 있으면 새 경쟁을 만들지 않는다. 투수의 정상적인 선발 로테이션은 대상에서 제외한다.

홈과 수신함에서 같은 주전 경쟁 컴포넌트를 사용하며, 방침은 모달에서 고른다. 보고를 읽기만 해서는 결정이 처리되지 않는다. 경기 시작과 연전 위임은 답변을 기다린다. 답변 이후에는 매 경기 멈추지 않고 진행 상황을 기록한다.

| 선택 | 다음 6경기의 선발 약속 | 즉시 반응 |
| --- | --- | --- |
| 공개 주전 경쟁 | 두 선수 각각 2경기 이상 | 베테랑 사기 +2, 유망주 +1, 각각 감독 관계 +1 |
| 유망주를 계속 믿는다 | 유망주 4경기 이상 | 베테랑 역할을 로테이션으로 변경, 사기 −3·관계 −2; 유망주 사기 +2·관계 +1 |
| 고참에게 중재를 맡긴다 | 두 선수 각각 1경기 이상 | 실제 1군의 30세 이상 동료가 중재. 중재자 충성도+나이가 베테랑 완고함+25 이상이면 수용(베테랑 사기 +2), 아니면 난항(−1) |

중재자는 건강하고 구단에 있어야 하며 실제 주장으로 지정한 것은 아니다. 선택할 때 중재자가 없으면 해당 선택을 거부한다. 주전 경쟁 중인 두 선수에게 기존 출전 부족 면담을 중복 발행하지 않는다. 미답변 상태에서 휴가를 가면 복귀까지 방침 결정을 보류한다.

약속은 완료된 공식 경기의 실제 선발 명단과 타격 기록으로 평가한다. 부상·대표팀 차출 기간에는 평가 경기 수를 늘리지 않는다. 건강한 선수를 2군으로 내린 것은 출전 기회로 인정하지 않는다. 6경기가 되면 약속 대상 선수별로 이행 시 사기 +4·관계 +2, 불이행 시 사기 −6·관계 −3을 한 번 적용한다. 두 선수가 각각 6타수 이상이면 경쟁 기간 타율이 더 높은 선수에게 사기 +2를 추가한다. 유망주 지지 방침을 지키고 유망주가 3안타 이상 기록하면 베테랑 사기 +1을 부여한다. 선발 명단을 강제로 바꾸지는 않는다.

사기는 기존 경기 컨디션·능력 계산에 반영되며 새 경쟁 시스템에서 고정 승패를 지급하지 않는다. 시즌 종료·선수 이동·감독 퇴임/이동은 경쟁을 종료하고 남은 출전 약속에 불이행 불이익을 주지 않는다. KBO 포스트시즌 직행 대기는 시즌 종료로 보지 않는다. 동시에 한 건만 열고 같은 베테랑에게는 42일 동안 다시 제안하지 않는다. 경쟁 이력은 최근 12건, 경기 중복 방지 ID는 사례별 최근 8건으로 제한하며 API 요청의 원자적 중복 방지를 함께 사용한다.

## 코드와 저장

- 공유 계약과 조회: `packages/shared/src/tactical-duel.ts`, `lineup-competition.ts`.
- 실제 경기·약속·사기 변경: `apps/api/src/domain/tactical-duel.ts`, `lineup-competition.ts`, `match-simulation.ts`, `game-engine.ts`.
- 선택 상태와 저장 요청: `useTacticalDuel`, `useLineupCompetition`. 화면은 `TacticalDuelPanel`, `TacticalDuelSummary`, `LineupCompetitionPanel`로 재사용한다.
- 스타일: `apps/web/styles/tactical-stories.css`. 프리뷰의 밝은 분석 영역은 명시적인 글자색을 사용한다.

D1 테이블이나 외부 서비스를 추가하지 않는다. 기존 커리어의 선택적 필드로 확장하고 기존 revision·요청 ID·소유자 및 슬롯 격리 경로를 사용한다. 주전 경쟁 답변은 두 선수와 이야기 상태를 함께 저장하는 전체 커리어 명령이며, 한 선수만 저장하는 `respondNews` 경로는 사용하지 않는다. 런타임 카탈로그는 기존 D1 v17을 유지한다. 추가 요금제 변경은 없다.

검증 항목은 실제 시뮬레이션 변화·고정된 대응·기존 경기 재생·이야기 생성 조건·6경기 이행과 성적·부상/퇴임/휴가 예외·D1 재시도/재접속/다른 소유자 차단·모달 조작과 가독성을 포함한다. 수행 결과와 공개 배포 식별자는 `WORKLOG.md`에 기록한다. 장기적인 난이도 균형이나 실제 리그 전체의 전술·선수 심리를 재현한 것은 아니다.
