# FM형 구단 운영 기능 점검 — 2026-09-08 / 후속 갱신 2026-09-09

> 후속 변경: 경기 프리뷰 편집과 경기 중 교체·직접 작전, 스카우트 파견, 개인 육성·멘토링, 경기 전후 인터뷰·코치 위임과 Space 진행을 추가했다. 현재 경기 처리 범위·제한은 [Worker/경기 타임라인 문서](worker-performance.md)를 우선한다. 부상·재활 등 남은 시스템은 아래 표에서 계속 추적한다. 배포 대상은 WORKLOG의 확인된 SHA를 따른다.

현재 게임은 FM 전체 기능을 구현한 상태가 아니다. 날짜 진행·단계별 영입·개인 성장의 기본 흐름은 연결됐지만, 관찰해서 선수를 찾고 장기간 육성하며 구단 전체를 운영하는 시스템은 아직 단순하다.

초기 점검 기준은 구현 커밋 `2ef0c3378b6b73710f30967ac8e215f509b6e6e3`이며 아래에는 9월 9일 후속 구현을 반영했다. 배포 여부와 대상 소스는 [WORKLOG](../WORKLOG.md)의 최신 배포 기록을 따른다. 아래의 ‘구현’은 명시한 범위에서 동작한다는 뜻이며 FM과 동일한 깊이·모든 기능의 재현을 의미하지 않는다. 모든 FM 버전의 기능을 망라한 목록이나 완료율 산정은 아니다.

## 2026-09-09 플레이 흐름 개선

- 수신함의 주제/처리 필요/검색, 발신자와 구조화 보고, 만료 선수별 재계약과 협상 답변의 직접 연결을 추가했다. 홈의 만료 안내도 계약 대상 목록으로 이어진다.
- 선수 조건 제안·역제안·재협상·최종 계약서를 하나의 협상실에서 이어가고, 선수/코치의 최종 서명은 구단 사무실 화면에서 진행한다. 계약 옵션/성과 조건/경쟁 구단은 아직 미구현이다.
- 모바일 경기는 원정/홈 타순을 두 열로 표시하며 현재 타자·타석 결과를 강조한다. 재생 중에는 저장된 기록만 읽고 선수·전술 적용 때 서버에서 미래 기록을 갱신한다. PC는 구장과 별도 타석 요약을 함께 보여준다.
- 계약서에서도 연봉을 조율하고 다시 제안할 수 있다. 기존 기간과 구단 합의를 유지하며 상대의 재합의 후 새 서명으로 체결한다.
- 스카우팅 센터의 리그/개인 파견, 7·14·28일 기간과 비용/진척, 관찰 능력 범위·신뢰도/추천, 관심 명단과 후보 3명/소속 선수 비교를 추가했다. 수신함 보고에서 선수 상세와 계약 제안으로 이어진다. 테스트 입단과 시설/광범위한 스태프 위임은 남아 있다.
- 선수단 OVR과 상세 능력의 상승·하락 화살표/변화량, 관찰 기준 날짜, 상승·하락 필터와 성장 보고를 추가했다. 개인 능력 집중·강도·주간 휴식·멘토·목표 수치를 지정하고 목표 달성 시 수신함으로 알려준다. 관찰 이력과 평가가 없는 능력의 상승을 만들지 않는다.
- 경기 전후 기자 질문 두 개와 라커룸 대화, 답변 카드·코치 위임, 실제 사기 변화와 최근 20회 대화 기록을 추가했다. 경기 결과/실책/최근 성적/선발 컨디션을 반영하며 공개 발언의 팬·구단주 장기 평가는 남아 있다.
- 아래 초기 표의 미구현 장기 운영 시스템을 UI 개선만으로 완료 처리하지 않는다. 최신 테스트/배포 증거는 WORKLOG의 해당 날짜를 따른다.

## 비교 기준

### 2026-09-09 추가 점검과 진행 순서

사용자는 게임 전체의 FM형 흐름, 경기 전/후 인터뷰, 경기 중 도루·번트 지시와 추가 누락 기능 탐색을 요청했다. 아래 우선순위는 구현 순서이며 완료 선언이 아니다.

1. 수신함의 필수 결정/안 읽은 보고 → 경기 전 준비 → 경기장 → 해당 경기 보고/다시보기로 연결한다. 화면 이동과 경기 시뮬레이션을 구분하고 날짜 변경은 서버에서만 수행한다.
2. 타석별 도루·희생번트·히트앤드런을 상황에 맞게 지시한다. 저장된 과거 이벤트와 기존 커리어를 유지하며 이후 타임라인만 다시 생성한다.
3. 경기 전/후 기자 질문·답변, 선수 반응, 라커룸 팀 대화와 수석 코치 위임을 경기 흐름에 넣는다. 실제 경기 상황과 선택 결과를 저장하고 같은 인터뷰의 효과를 반복 획득하지 못하게 한다.
4. 부상/의료실/재활, 구단주 목표·감독 평가, 스태프 책임 위임, 계약 옵션/성과급, 시즌별 선수 이력, 영입 계획 회의·지역 관찰 지식, 성격·리더십·선수 특성은 현재 코드에서 빠졌거나 단순한 부분이다. 아래 도메인별 미완성 범위를 계속 구현/검증한다.

공식 자료의 [경기일 경험](https://www.footballmanager.com/fm26/features/where-storytelling-evolves-fm26s-match-day-experience), [상호작용과 개인 목표](https://www.footballmanager.com/features/individual-player-targets-and-interaction-logic), [언론과 팬 반응](https://www.footballmanager.com/features/supporter-confidence), [업무 위임](https://www.footballmanager.com/the-dugout/delegating-success-football-manager-26), [영입 계획 회의](https://www.footballmanager.com/features/recruitment-revamp)를 비교 기준으로 확인했다. 각 문서는 FM23/24/26 등 서로 다른 버전의 기능을 다루므로 이를 하나의 특정 버전과 완전히 같다고 설명하지 않는다. 야구 구현의 공식 규칙 재현 여부는 별도로 검증한다.

경기 계산 코드 점검: 타자 컨택에 `0.7 + condition × 0.003`, 투수 종합 능력에 `0.75 + condition / 400`을 적용한다. 장타·신중한 타격·도루·수비 깊이 지시와 전술 숙련도, 선수 사기·코치·포지션 숙련도가 연결돼 있다. 경기 중 투구 누적에 따른 피로 저하, 피로의 파워/주루/수비 전반 반영은 아직 미흡하며 향후 검증·보강 대상이다. 확률과 계수는 게임 모델로서 현실 야구의 통계적 보정을 완료했다는 뜻이 아니다.

FM 공식 자료의 [영입과 선수단 계획](https://www.footballmanager.com/fm26/features/powered-transferroom-fm26s-recruitment-revamp), [유소년 육성](https://www.footballmanager.com/the-dugout/developing-and-maximising-your-youth-intakes-fm26), [스태프 업무 위임](https://www.footballmanager.com/the-dugout/delegating-success-football-manager-26)을 참고했다. 영입 목표·관찰 보고·시설과 성격의 육성 영향·스태프에게 맡기는 업무를 비교 축으로 삼았다. 야구의 드래프트·트레이드·등록 제도는 별도의 야구 게임 요구사항이며 FM 축구 규칙을 그대로 옮길 대상은 아니다.

## 다음에 채울 기능

아래 순서는 사용자가 요청한 ‘선수를 찾아 영입하고 키우는 재미’와 감독의 직접 결정 기회를 기준으로 한 제안이다. 이 점검에서 전부 구현하겠다는 일정 약속은 아니다.

1. **경기 중 투수 관리와 부상·재활**: 투구 누적 피로와 불펜 워밍업을 교체 판단에 연결한다. 부상은 회복 기간·의료실·재활·명단 대체를 함께 설계한다. 직접 투수/대타 교체와 도루·번트 지시는 이미 구현한 범위다.
2. **육성의 장기 기록과 환경**: 시즌이 바뀌어도 선수별 통산 이력과 수상을 보존하고 훈련 세션·담당 코치·시설·성격의 영향을 확장한다. 능력 목표·강도·휴식·멘토링과 성장 보고는 구현한 범위다.
3. **영입 경쟁과 스태프 운영**: 경쟁 구단 제안·계약 옵션/성과급·테스트 입단·장기 지역 관찰 지식, 스카우트 임무 관리와 협상 대행을 추가한다. 기간별 관찰·관심 명단·비교·협상 연결과 인터뷰 위임은 구현한 범위다.
4. **구단과 감독의 장기 운영**: AI 선수단 구성, 리그별 규정, 구단 목표·예산·감독 경력과 팬/언론의 장기 평가를 연결한다. 신인 공급은 드래프트·아마 관찰·육성 시설로 확장한다.

## 검증 범위와 한계

초기 날짜 진행·협상·성장 구현은 79개 자동 테스트를 통과했고, 9월 9일 인터뷰 완료 화면 보완까지 반영한 최종 소스는 전체 120개 테스트, 운영 빌드, 타입·lint·포맷 검증을 통과했다. 로컬 브라우저에서 날짜별 저장과 정지, 코치·선수 협상/재접속, 관찰·성장 보고, 직접 작전, 전술 초안의 한 번 저장, Space 제어와 경기 전후 인터뷰까지 확인했다. 각 확인의 실제 범위와 모바일/PC 결과는 WORKLOG에 기록했다. 기존 진행 경기의 결과 해시 회귀도 유지했다. 이 후속 구현에 SQL 스키마 변경이나 커리어 초기화는 없다.

위 결과가 몇십 년 장기 밸런스, 모든 실제 선수 데이터, 모든 국가 규정, FM과 동일한 경기 현실성을 검증했다는 뜻은 아니다. 성장 유형·협상 선호·실명 코치 능력은 게임용 모델이며 실제 인물의 평가·미래 사실로 취급하지 않는다. 미구현 항목은 이 문서에서 확인·우선순위화했으며, 화면만 만들어 완료로 표시하지 않았다.
