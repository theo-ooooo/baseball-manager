# 0.5.17 감독의 경험과 인연

감독 프로필의 지도 능력에 선수 출신 특성과 경험을 표시하고, `제자 · 인맥`과 `업적` 탭을 추가했다. 수신함의 경기 결과에는 `작전 복기`를 제공한다. 기존 선수 시절·재임 이력은 유지한다.

## 경기와 운영에 반영되는 범위

- 포수: 불펜 +3, 선수단 장악 +1. 투수: 불펜 +4, 평가 +1. 내야수: 작전 +3, 육성 +1. 외야수: 작전 +2, 평가 +2. 타자: 육성 +3, 작전 +1. 경력이 없는 감독은 특성을 추정하지 않는다. 실제 인물의 능력을 평가한 수치가 아닌 게임 규칙이다.
- 내 감독의 시작 능력을 최초 적용 때 저장한다. 이후 평판 변화가 지도 능력을 다시 계산하지 않는다. 경험 100마다 해당 능력 +1, 경험 보너스는 최대 +12, 최종 능력은 95 이하다. 기존 경기·훈련·대화·관찰 효과에 그대로 반영하며 새 경기의 양 팀 능력은 시작 시 고정한다.
- 완료 경기에서 작전 3 XP와 직접 사인 성공 보너스 최대 2, 불펜 3 XP와 무실점 구원 등판 보너스 최대 2를 얻는다. 하루 상한은 각 10 XP다. 연습경기도 지도 경험은 쌓지만 공식 승수에는 합산하지 않는다.
- 실제 성장한 23세 이하 선수를 훈련한 날 육성 1 XP, 직접 마친 인터뷰 1 XP와 긍정 반응 1 XP(하루 최대 4), 관찰 보고 1명당 평가 2 XP(하루 최대 6)를 얻는다. 위임한 인터뷰에는 감독 경험을 주지 않는다. 같은 날짜·이벤트 재처리를 중복 지급하지 않는다.

## 관계와 업적

실제로 훈련하거나 출전시킨 선수, 함께 경기를 운영한 코치를 기록한다. 신뢰는 함께한 훈련·경기와 직접 대화 반응에 따라 변한다. 긍정 메시지는 신뢰에 따라 최대 0.25의 원점수 보조를 받되 기존 사기 변화 상한을 넘지 않는다. 친분 있는 코치는 연봉 기대치를 최대 8% 완화하며 거부 사유·예산·최종 계약 절차는 유지한다.

내 가상 선수 이력에는 가상 동료 코치 1명이 연결된다. 별도 난수로 이름·보직·능력을 결정해 경기 난수를 소모하지 않으며 재접속·이직 후에도 같은 인물이다. 인맥에서 프로필을 열거나 직접 코치직 제안을 보낼 수 있다. 실명 인물에게 확인되지 않은 과거 친분을 부여하지 않는다.

23세 이하 시기에 함께 훈련한 날이 28일 이상이고 관측된 기량 성장 합이 0.5 이상인 선수는 제자로 기록한다. 5경기 이상 함께한 선수를 상대 팀에서 만나면 재회 질문이 나오며 같은 선수는 30일 이내 재질문하지 않는다. 관계 목록은 최대 200명이며 오래된 약한 인연부터 정리하되 제자·가상 동료·현재 구단 관계는 우선 유지한다.

첫 승, 10·50·100·300·500·1000승, 시즌 우승, 제자의 공식 경기 기용, 제자의 첫 관측 국가대표 선발을 업적으로 저장한다. 기능 적용 이전의 기록은 소급 합산하지 않고 시작일을 표시한다. 실제 선수의 최초 1군 데뷔나 실제 대표 선발 이력이라고 주장하지 않는다.

## 작전 복기와 저장

완료한 실제 플레이에서 직접 사인과 위임 판단, 성공 여부·득실점·선수 이름을 보여 준다. 직접 사인이 있으면 최근 3건, 없으면 7회 이후 2점 차 이내의 지시를 우선 노출하고 전체 기록은 펼쳐 볼 수 있다. 양 팀 카드의 등급·사용 장면과 증강의 1회 발동·상대 카드 무효화·미발동을 구단별로 표시한다. 한 사인 때문에 승리했다고 추정하지 않는다.

새 D1 테이블 없이 커리어 상태와 기존 경기 아카이브를 사용한다. 이미 진행 중인 경기의 감독 능력 스냅샷과 구버전 결과를 유지한다. FA 관찰에 필요한 최신 시즌 기록은 최대 9명을 묶어 조회하고 실시간 재생 명령에는 추가 조회하지 않는다. 호스팅 식별자와 Cloudflare 요금제를 변경하지 않았다.

## 검증 범위

실제 경기 엔진·저장 복원·중복 보상·기존 진행 경기·D1 FA 견적/관찰·동료 코치 협상 및 최종 채용을 테스트한다. 브라우저는 격리된 프로덕션 Worker/D1를 사용해 감독 프로필, 인맥 제안 모달, 위임 경기 결과와 모바일 표시를 확인한다. 장기 시즌 승률 균형이나 모든 실명 인물의 완전한 역사·인맥을 보장하지 않는다. 배포 결과와 최종 테스트 수는 WORKLOG.md에 기록한다.
