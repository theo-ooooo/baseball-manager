# DUGOUT 1.0.1 — 트레이드 추천과 계속 이어가는 협상

트레이드 센터에서 “이 선수를 받고, 이 선수를 내주는 안”을 추천받고, 상대가 역제안하면 선수와 현금을 다시 조정해 협상을 이어갈 수 있다.

## 이용 방법

1. 트레이드 센터의 **트레이드 선수 추천**을 연다. 받을 선수, 보낼 선수, 추가 현금, 전력 보강 이유와 선발 공백을 최대 3개 안으로 확인한다.
2. **이 안으로 조건 검토**를 누르면 협상 모달에 해당 조건이 채워진다. 이 단계에서는 저장된 선수·예산·협상을 바꾸지 않는다.
3. 특정 선수를 먼저 선택한 경우 **이 선수를 받을 교환 대가 추천**으로 대가를 다시 찾는다. 마감 영입 경쟁의 조건 모달에서도 사용할 수 있다.
4. 답변이 오면 **조건 수정해서 다시 제안**으로 역제안의 선수/현금을 불러와 수정한다. 같은 협상에서 2차, 3차로 계속 제안하며 최근 6개 차수의 우리 조건과 상대 답변을 조회할 수 있다.
5. **이 조건으로 트레이드 확정**을 눌러야 선수와 현금이 실제로 이동한다. 원래 협상 기한은 늘어나지 않고, 마감 경쟁의 대상 선수는 바꿀 수 없다.

## 규칙과 구현 범위

- 추천은 현재 선수단과 예산, 상대의 기존 교환 가치 규칙을 사용한다. 핵심/프랜차이즈 선수는 자동 추천의 보낼 선수에서 제외한다. 부상/대표팀 차출, 다른 협상에 포함된 선수, 정원·포지션·예산·현금 가치 상한을 확인한다.
- 마감 영입 추천은 경쟁 구단의 기존 조건도 고려한다. 추천 조회나 조건 선택만으로 영입 성공을 확정하지 않는다.
- 수락 대기·역제안·거절도 기한 안에는 수정 가능하며 철회·완료·기한 만료한 협상은 다시 열지 않는다. 수락을 미루는 동안 소속이나 전력 조건이 바뀌면 서버에서 다시 검증한다.
- 추천은 읽기 전용 서버 요청으로 계산하며 저장과 난수를 변경하지 않는다. 최대 12개 대상 × 29개 교환 조합으로 탐색 범위를 제한하고, 공개 응답은 선수 식별/이름/포지션/나이/교환 조건으로 제한한다. 숨겨진 잠재력 수치를 내려주지 않는다.
- 화면/상태/비동기 요청은 재사용 컴포넌트와 커스텀 훅으로 분리했다. 기존 서버 명령, 소유자 인증, 저장 리비전, 중복 요청 방지 체계를 유지한다. 기존 커리어 초기화나 D1 스키마 변경은 필요하지 않다.

## 검증

프로덕션 빌드 및 전체 440개 테스트, 타입·린트·포맷 검사를 통과했다. 새 도메인 6건/실제 Worker-D1 통합 1건에 추천 비변경성, 유효한 교환안, 권한, 9차 재협상과 최근 6건 기록 한도, 기한/예약/마감 대상 보호, 반복 요청과 최종 교환을 포함했다.

격리된 실제 Worker/D1로 PC/390px 추천→조건 모달→제안, 2→3→4차 역제안→새로고침→최종 확정, 마감 영입 추천→조건 입력→실제 우세 입찰 저장을 브라우저에서 확인했다. 최종 확정 전후의 실제 선수단과 현금 정산을 저장 데이터로 비교했다. 공개 사용자 저장은 수정하지 않았다.

현재 시점의 규칙 기반 추천이며 미래의 수락, 장기 밸런스, 실제 국가별 트레이드 제도의 완전한 재현을 보장하지 않는다. 보호/예산 조건을 만족하는 안이 없으면 추천 없음으로 표시한다. 공개 배포 결과와 실행 빌드 식별자는 `WORKLOG.md`의 배포 완료 기록에서 확인할 수 있다.
