# DUGOUT 1.0.2 — 경기 진행과 저장 안내 정리

공개 서비스에서 KIA 단축 커리어 두 시즌, 총 47경기를 직접 진행하며 발견한 불편을 수정했다.

- 보고나 계약 답변이 남아 연전 위임을 할 수 없으면 해당 처리 화면으로 바로 이동한다. 정상적인 규칙 안내를 저장 실패로 표시하지 않는다.
- 연전 후 날짜가 바뀌면 이전 날짜 안내가 사라진다. 진행 달력의 지난 경기는 상대와 실제 스코어를 표시한다.
- 다음 시즌에 작년 연전 완료 안내가 남지 않는다.
- 코치 인터뷰 설명을 실제 상황별 선택에 맞추고, 새 선발 추천 보고의 사기 수치를 읽기 쉽게 표시한다.

기존 저장을 그대로 사용하며 데이터베이스 마이그레이션은 없다. 저장 응답이 끊기거나 손상되면 기존 복구 경고와 동일 요청 재시도를 유지한다. 성공적인 저장 재조회 후에는 경고를 해제한다.

프로덕션 빌드, 전체 446개 테스트와 타입·린트·포맷 검사 통과. 수정본을 로컬 Worker/D1의 PC·390px 브라우저에서 확인했다. 두 시즌의 실제 결과와 확인 범위, 일괄 서명·반복 보고의 후속 개선점은 [실사용 기록](playthrough-2026-09-16.md)에 정리했다. 공개 배포 식별자와 최종 확인 결과는 `WORKLOG.md`의 배포 완료 기록에 남긴다.
