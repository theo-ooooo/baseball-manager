# DUGOUT 1.0.5 — 다시 결정하고 싶은 순간으로

실제 플레이에서 발견한 반복을 세 곳에서 줄였다.

- **경력에 맞는 면접:** 지난 순위, 약속한 목표, 경질·계약 만료 이력에 따라 질문과 답변 평가가 달라진다. 성공한 운영을 재현할지 실패를 어떻게 바꿀지 설명하며, 선임 평가와 취임 예산 요청 판단에 반영한다.
- **이번 이닝만 코치에게:** 기회·위기 모달에서 남은 이닝을 맡기고 다음 이닝부터 직접 지휘한다. 코치가 실제 작전과 카드를 사용하며, 돌아오면 전후 점수와 남은 카드를 확인한다. 사용한 카드의 재사용은 서버에서도 막는다.
- **휴가 복귀 요약:** 남은 결정과 중요한 소식을 먼저 보여주고 해당 보고로 바로 이동한다. 휴가 중 승패를 함께 보여주며 일반 보고는 접어서 모은다. 조기 복귀와 새로고침 후에도 같은 보고를 확인할 수 있다.

프로덕션 빌드, 전체 459개 테스트, 타입·린트·포맷 검사를 통과했다. 실제 로컬 Worker/D1에서 면접→선임 제안, 이닝 위임→직접 지휘 복귀, 7일 휴가→보고 처리와 390px 화면을 확인했다.

기존 저장을 이어 쓸 수 있으며 D1 스키마 변경은 없다. 면접은 기존 6문항과 제출한 대화를 보존한다. 복귀 요약은 현재 보관된 경기·메일 범위로 계산한다. 게시 결과는 `WORKLOG.md`에 기록한다.
