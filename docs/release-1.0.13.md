# DUGOUT 1.0.13 — 선수 계약 기간과 베테랑 은퇴 수정

공개 계약 자료로 확인한 실명 선수 27명의 계약 종료 시즌을 반영했습니다. 전준우·박세웅은 2027년, 김원중·최정은 2028년, 이정후는 2029년, 류현진은 2031년까지입니다. 선수 상세와 협상창에서 반영 여부와 발표 자료를 확인할 수 있습니다. 표시되는 연수는 잔여 시즌 수입니다.

다른 구단 선수가 계약 만료 후 계속 잔여 1년으로 고정되던 처리를 수정했습니다. 만료 때 나이·기량에 따라 1~5년으로 재계약합니다.

잔여 계약이 여러 시즌인 선수는 자동 은퇴 대상에서 제외합니다. 계약 만료 선수도 나이·현재 기량·출전을 함께 고려하며, 활약 중인 38~40세 베테랑은 나이만으로 은퇴하지 않습니다.

기존 저장의 미변경 초기 계약을 보정하고, 게임에서 체결한 계약·이적·방출과 이미 확정된 은퇴는 보존합니다. 전체 선수의 실제 계약을 완전히 복제한 것은 아니며, 미확인 계약·연봉은 게임 설정이고 옵트아웃·연장 옵션은 구현하지 않았습니다.
